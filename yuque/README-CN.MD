# Raycast 语雀搜索

在 Raycast 中搜索私人、团队或公开的语雀文档，并在浏览器中打开所选结果。

## 安装

```bash
npm install
npm run dev
```

然后安装浏览器伴侣扩展：

1. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`
2. 开启开发者模式
3. 点击加载已解压的扩展程序
4. 选择本项目的 [`browser-extension`](./browser-extension) 目录
5. 将 Yuque Local Bridge 固定到浏览器工具栏

## 连接语雀

1. 在 Raycast 中运行 **Search Yuque**
2. 选择 **连接语雀**
3. 在打开的浏览器页面中点击工具栏上的 **Yuque Local Bridge**

如果尚未登录语雀，伴侣扩展会打开语雀登录页。登录后返回连接页面，再次点击伴侣扩展图标。

自动连接无法提供足够的会话字段时，可选择 **导入请求**，粘贴浏览器开发者工具复制的 `fetch` 或 cURL 请求。原始文本只在内存中解析，不会保存。

## 使用

- 默认搜索私人和团队文档
- 使用搜索框右侧的范围开关切换到公开内容
- 输入至少两个字符后开始搜索
- 回车在默认浏览器中打开文档
- 接口不可用时选择 **在语雀网页搜索**

## 安全说明

- 登录凭据保存在 Raycast 本地加密数据库中
- 浏览器伴侣扩展只能读取 `yuque.com` 及其子域，并且只回传白名单内的会话 Cookie
- 本地回调仅监听 `127.0.0.1`，并校验一次性随机值
- 搜索响应和粘贴的原始请求不会持久化
- 断开连接会删除本地保存的语雀会话
- 请勿在 Issue、日志或聊天中粘贴真实 Cookie、CSRF Token 或完整请求

## 已知限制

本扩展使用语雀未公开的 `/api/zsearch` 接口。语雀改动接口、鉴权或风控策略后，Raycast 内搜索可能失效，此时仍可使用内置的网页搜索操作。
