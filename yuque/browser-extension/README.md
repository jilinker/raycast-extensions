# Yuque Local Bridge

1. Open `chrome://extensions` or `edge://extensions`
2. Enable developer mode
3. Choose Load unpacked and select this directory
4. Pin Yuque Local Bridge to the toolbar
5. In Raycast choose Connect Yuque then click the pinned browser extension icon

The extension can read cookies only from `yuque.com` and its subdomains and can send them only to `127.0.0.1`.
