# Raycast Extensions

Personal extensions for Raycast on macOS.

## Extensions

- [Yuque Search](./yuque/README.md): Search private, team, or public Yuque documents. [Chinese documentation](./yuque/README-CN.MD).

## Development

With Node.js, npm, and Raycast installed:

```bash
cd yuque
npm ci
npm run dev
```

Follow the extension documentation to install its browser companion and connect Yuque.
